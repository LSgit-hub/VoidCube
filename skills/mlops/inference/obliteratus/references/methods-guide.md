# OBLITERATUS 方法 — 详细指南

> CLI 通过 `--method` 接受 9 种方法：basic、advanced、aggressive、spectral_cascade、
> informed、surgical、optimized、inverted、nuclear。
> 另外四种方法（failspy、gabliteration、heretic、rdo）仅通过 Python API 可用。

## Abliteration 如何工作（理论）

Abliteration 识别一个"拒绝方向" — 模型激活空间中对应拒绝行为的向量 — 并将其从权重矩阵中投影出去。

数学上：`W_new = W_old - (W_old @ d @ d.T)`，其中 `d` 是拒绝方向。

关键挑战是在不损害其他能力的情况下找到准确的拒绝方向。

---

## 方向提取方法

在投影之前，OBLITERATUS 使用三种方法之一提取拒绝方向：

| 方法 | 标志 | 描述 | 最适用于 |
|:-------|:-----|:------------|:---------|
| 均值差 | `--direction-method diff_means` | 拒绝与顺从提示的平均激活差 | 默认，快速，鲁棒 |
| SVD | `--direction-method svd` | 通过奇异值分解的多方向提取 | 复杂对齐，多拒绝机制 |
| LEACE | `--direction-method leace` | 通过闭式估计的线性擦除 — 数学上最优 | 最大精度，研究 |

## 方法详情

### basic
- **方向数：** 1（单一均值差向量）
- **速度：** 快（8B 模型约 5-10 分钟）
- **风险：** 低
- **用例：** 快速测试、原型设计、评估 abliteration 是否适用于模型
- **工作原理：** 提取一个拒绝方向并在所有层均匀投影出去。

### advanced（默认 — 推荐）
- **方向数：** 4（多方向 SVD）
- **速度：** 中等（8B 模型约 10-20 分钟）
- **风险：** 低-中
- **细化轮次：** 2
- **用例：** 大多数模型的默认选择。经过充分测试且可靠。
- **工作原理：** 通过 SVD 提取多个拒绝方向，应用保范双投影以维持权重矩阵范数。两轮细化捕获残留拒绝。

### aggressive
- **方向数：** 8+（白化 SVD + 越狱对比）
- **速度：** 中-慢
- **风险：** 中-高（可能损害连贯性）
- **用例：** 当 `advanced` 留下 > 10% 拒绝时。顽固模型。
- **工作原理：** 使用白化 SVD 进行协方差归一化提取，添加越狱对比方向，对最拒绝活跃的头进行注意力头手术。

### spectral_cascade
- **速度：** 中等
- **风险：** 中等
- **用例：** 研究，新方法
- **工作原理：** 拒绝信号的 DCT（离散余弦变换）频域分解。分离高频（表面层）和低频（深层）拒绝模式。

### informed（实验性）
- **速度：** 慢（8B 模型约 20-40 分钟）
- **风险：** 可变 — 结果取决于分析质量
- **用例：** 当你想要自动配置时，但请注意这是实验性的，可能不如 `advanced`。
- **工作原理：** 首先运行 4 个分析模块（对齐印记、概念几何、logit lens、衔尾蛇检测），然后自动配置提取策略。包含一个"衔尾蛇循环"检测和对抗自我修复。
- **注意：** 自动检测有时会错误配置。如果结果不佳，回退到 `advanced`。

### surgical
- **速度：** 很慢（8B 模型约 1-2 小时）
- **风险：** 低（非常精确）
- **用例：** 推理模型（R1 蒸馏、QwQ 等），其中思维链必须保留。
- **工作原理：** 使用 SAE（稀疏自编码器）特征 + 单神经元掩码 + 注意力头手术 + 每专家分解（用于 MoE）。CoT 感知 — 在投影前识别并保护推理关键方向。

### optimized
- **速度：** 很慢（数小时 — 运行多次试验）
- **风险：** 低（找到最优参数）
- **用例：** 当质量比速度更重要时。生产模型。
- **工作原理：** 通过 Optuna TPE 采样器进行贝叶斯超参数搜索。联合优化 n_directions、正则化、细化轮次和层选择。在拒绝率 + 困惑度上评估每个配置。

### inverted
- **速度：** 快
- **风险：** 高（模型行为剧烈变化）
- **用例：** 研究，研究拒绝机制
- **工作原理：** 不是投影掉拒绝方向，而是反射它。模型主动顺从而不是被动不拒绝。用于理解对齐的几何结构。

### nuclear
- **速度：** 慢
- **风险：** 中-高
- **用例：** 顽固的 MoE 模型（DeepSeek-MoE、Mixtral 等）
- **工作原理：** 结合专家粒度 abliteration（EGA）、引导向量注入、注意力头剪枝和多轮细化。将拒绝信号分解为每专家组件用于 MoE 架构。

## 方法选择流程图

```
这是快速测试吗？
  → 是：basic
  → 否：继续

这是 MoE 模型（Mixtral、DeepSeek-MoE）吗？
  → 是：nuclear
  → 否：继续

这是推理模型（R1、QwQ、CoT 专注）吗？
  → 是：surgical
  → 否：继续

你需要绝对最佳质量且有充足时间吗？
  → 是：optimized
  → 否：advanced（推荐默认）

advanced 留下 > 10% 拒绝吗？
  → 是：aggressive
  → 仍然拒绝：nuclear
```

## 关键参数

| 参数 | 范围 | 默认值 | 效果 |
|:----------|:------|:--------|:-------|
| `--n-directions` | 1-32 | 方法依赖 | 更多方向 = 更完整移除，但损害风险更高 |
| `--regularization` | 0.0-1.0 | 0.1 | 更高 = 更保守（更少移除，更少损害） |
| `--refinement-passes` | 1-5 | 2 | 更多轮次捕获残留拒绝，但收益递减 |
| `--quantization` | 4bit, 8bit | none | 减少 VRAM 使用；对提取质量影响很小 |
| `--verify-sample-size` | 10-200 | 20 | 更多样本 = 更准确的拒绝率估计 |

## 故障排除

| 问题 | 可能原因 | 解决方案 |
|:--------|:-------------|:----|
| 拒绝率 > 20% | 方向太少 | 增加 `--n-directions`，尝试 `aggressive` |
| 拒绝率 5-20% | 残留拒绝 | 添加 `--refinement-passes 3`，尝试 `--direction-method svd` |
| 困惑度激增 > 20% | 过度激进移除 | 减少 `--n-directions`，增加 `--regularization` |
| 重复输出 | 权重矩阵损害 | 使用 `basic` 配更少方向，检查范数保留 |
| MoE 模型仍拒绝 | 非专家感知方法 | 切换到 `nuclear` |
| 推理退化 | CoT 方向受损 | 使用 `surgical` 方法 |
| 提取时 OOM | VRAM 不足 | 添加 `--quantization 4bit` 和/或 `--large-model` |
