# VoidCube 文档

文档面向实际使用者和维护者，先说明入口、前置条件和可观察结果，再说明配置、失败处理、边界与扩展方式。每个事实只保留一个权威来源，其他页面链接到它。

## 工作流程

1. 阅读根目录 `AGENTS.md`、`docs/testing.md` 和受影响代码，确认命令、路径、配置键和错误文本。
2. 按用户任务组织内容：快速入口、完整步骤、验证方式、故障排查和限制；删除过时的计划、审查对话和重复清单。
3. 检查所有仓库内相对链接、代码块、命令参数、平台说明和示例输出。示例必须能在当前仓库复现，不能凭记忆补版本或接口。
4. 技能文档使用 YAML frontmatter 的 `name` 与 `description`，目录名和 `name` 保持一致；较长资料放在该技能的 `references/` 或 `templates/` 下。

## 验证

运行文档对应的命令或测试；文档改动至少运行 `git diff --check` 和相关契约测试。涉及技能时检查 `pytest tests/test_skill_registry.py -q`，涉及项目代码时按仓库规则运行完整门禁。报告未执行的真实环境验证，例如凭据、外部服务或 GPU 不可用。
