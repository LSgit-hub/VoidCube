# VoidCube 文档翻译

先确定源语言、目标语言、文档范围和术语表。翻译是语义保持工作：不添加源文档没有的能力、限制、参数或承诺，不翻译代码、命令、路径、配置键和协议字段。

## 检查清单

- 标题层级、列表顺序、表格列、代码块和示例数量保持一致。
- VoidCube、MemAI、技能名、工具名、配置键和错误码保持原样。
- 相对链接指向当前仓库存在的目标；链接文本可翻译，目标路径不可凭意愿改写。
- 中英文页面的警告、前置条件、失败处理和验证步骤逐项对应。
- 生成或人工修改后，从目标文档的真实入口复核命令和事实。

普通单段翻译直接完成，不要启动整套双语流程。大范围同步时分批处理，每批列出已翻译文件、未决术语、链接检查和未验证的外部步骤。
