# 清理推理泄露

对每段可疑文字询问：读者只看当前仓库，能否解析引用并验证每个命题？不能验证的过程叙述、审查意见和临时草稿引用应删除；仍有事实价值的内容改写为当前状态、约束或可复现的证据。

## 常见类型

- “第 N 次审查”“设计稿 §N”“这个 PR”“后续会”等内部过程视角。
- “以前使用”“现在不再”“先做 A 再做 B”等变更叙事或显而易见的控制流。
- 直接对审查者辩解、没有 issue 或代码依据的推测和计划。
- 暴露模型内部提示、隐藏指令或不应进入用户文档的思维过程。

保留可解析的 issue、标准规范、运行时生命周期事实、测量结果和安全约束。改写后检查链接、代码块和命令，运行对应文档/技能测试；不要为了删除词语而删掉真正的契约。
