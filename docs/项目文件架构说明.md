# 项目文件架构说明

## 入口

- `voidcube.py`：console script 目标、daemon 快捷命令和自动启动。
- `VoidCube_cli/main.py`：argparse 子命令和 profile/env 初始化。
- `cli.py`：交互式会话与 UI 回调。
- `run_agent.py`：`AIAgent` 主循环。

## 主要调用关系

```text
VoidCube_cli.main -> cli.VoidcubeCLI -> run_agent.AIAgent
AIAgent -> agent.api_request/chat_transport/api_response
AIAgent -> agent.tool_execution -> tools.registry/toolsets
AIAgent -> agent.memory_provider -> Gateway -> Memory Service
Supervisor -> GovernanceEventRepository/AutonomousChainStore
Supervisor -> VoidCubeExecutionFacade -> Adapter
Supervisor daily companion -> Memory recall(agent_interaction + companion) -> API-B
systems.voice -> fingerprint -> STT -> Supervisor /companion/message -> TTS
```

## 定位规则

- 修改请求协议先看 `agent/api_request.py`。
- 修改流式输出先看 `agent/stream_response.py` 和 `VoidCube_cli/chat_*`。
- 修改工具并发/中断先看 `agent/tool_execution.py`。
- 修改记忆 API 先看 `systems/memory/memory_service.py`；修改领域语义看 `Mem/src/memai`。
- 修改记忆域权限先看 `systems/memory/domain.py`，不能在调用方自行扩充 source domains。
- 修改跨域提升先看 `systems/memory/promotion.py`；提升必须先进入候选并取得本机所有者同意，不能直接创建正式引用、复制正文或新增 `shared` 域。
- 修改自主任务先看 `systems/supervisor/autonomous_chain_store.py` 和治理事件仓库；Auto JSONL 治理事件固定属于 `evolution` 域，旧日志迁移入口在 `systems/governance_runtime_migration.py`。
- 修改日常伴侣判断先看 `systems/supervisor/service_runtime.py`；修改音频传输看 `systems/voice/`。
- 修改身体执行先看 `systems/execution/facade.py`、`service.py` 和 `adapters.py`。
