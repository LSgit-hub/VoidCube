# VoidCube 语音系统说明

> 更新日期：2026-07-28
>
> 本文档说明 VoidCube 语音交互管道的完整架构——从麦克风输入到扬声器输出的每一环节。

## 二、模块概览

| 模块 | 文件 | 职责 | 核心技术 |
|------|------|------|---------|
| 音频采集 | `audio.py` | 持久 `sounddevice.InputStream`；录音/播放 | sounddevice + soundfile |
| 唤醒词检测 | `wake.py` | 本地 KWS 检测"你好，星子" | sherpa-onnx Zipformer |
| 语音活动检测 | `vad.py` | 判断是否在说话；静音收句 | Silero VAD ONNX |
| 声纹识别 | `fingerprint.py` | 本机所有者说话人过滤 | 3D-Speaker CAM++ (192维) |
| 语音转文字 | `stt.py` | 音频→文本 | 本地 faster-whisper 或 OpenAI-compatible 端点 |
| 文字转语音 | `tts.py` | 文本→音频播放 | edge-tts / ElevenLabs / OpenAI / Mistral / NeuTTS |
| 会话管理 | `session.py` | 单轮/持续监听协调；中断；清理 | asyncio |
| 配置 | `config.py` | `VoiceConfig` 统一配置数据类 | 环境变量 + 默认值 |
| 模型资产 | `model_assets.py` | 模型下载和 SHA-256 校验 | — |

## 三、两种使用模式

### 3.1 按钮单轮会话

```
用户点击 UI "开始语音会话"
  → 跳过 KWS
  → 直接进入 Silero VAD 收句
  → 8 秒内未开始说话 → 结束空会话
  → 收句完成 → STT → API-B → TTS → 播放
  → 会话结束（不恢复待唤醒）
```

### 3.2 持续监听

```
用户点击 UI "开始持续监听"
  → 持久 InputStream 保持活跃
  → KWS 循环检测唤醒词
  → 命中 → 120ms 本地提示音 → 进入收句
  → 收句完成 → STT → API-B → TTS → 播放
  → 播放期间暂停输入流（避免 TTS 回声误识别）
  → 恢复待唤醒
```

### 3.3 中断机制

- 持续监听播放期间可以中断
- 按钮会话可以中断等待中的持续监听
- 进入 Auto 模式时中断现有会话
- 麦克风关闭时拒绝所有语音操作

## 四、各模块详解

### 4.1 音频采集 (`audio.py`)

```python
# 核心配置
sample_rate: 16000 Hz
channels: 1 (单声道)
dtype: int16
```

- 使用 `sounddevice.InputStream` 创建持久音频流
- `AudioPlayer` 默认使用 `soundfile + sounddevice` 进程内播放，`ffplay` 作为兼容回退
- 录音临时文件在 `finally` 块中删除（`retain_raw_audio=False`）
- 播放支持中断（`AudioPlayer.stop()`）

### 4.2 唤醒词检测 (`wake.py`)

```python
# 默认配置
wake_word: "你好，星子"
wake_threshold: 0.25
wake_score: 1.5
wake_cue_enabled: True  # 命中时播放 120ms 提示音
```

- 使用 **sherpa-onnx Zipformer** 模型进行本地关键词识别
- 模型存储在 `runtime/voice/models/`，按 SHA-256 校验
- 未唤醒时，背景音不进入声纹、STT 或 API-B——完全本地处理
- KWS 只检测唤醒词，不调用 STT、声纹或 API-B

### 4.3 语音活动检测 (`vad.py`)

```python
# 默认配置
vad_threshold: 0.5
speech_start_timeout_seconds: 8.0   # 8 秒内未开始说话 → 返回
speech_end_silence_seconds: 3.0     # 连续 3 秒静音 → 收句
max_utterance_seconds: 45.0         # 最长单次话语
```

- 使用 **Silero VAD** ONNX 模型
- 连续 3 秒无语音才提交完整话语——**用户句中自然停顿不会被截断**
- 最长 45 秒单次话语边界保护
- 两个入口（KWS 唤醒 / 按钮单轮）共用同一个 VAD 管道

### 4.4 声纹识别 (`fingerprint.py`)

```python
# 默认配置
fingerprint_threshold: 0.50         # 匹配阈值
fingerprint_model: 3D-Speaker CAM++ # 192 维说话人嵌入
fingerprint_enabled: True           # 默认启用
```

**录入流程**：
1. 用户通过 UI 开始声纹录入
2. 采集三段各 3 秒音频
3. 每段提取 192 维 CAM++ 嵌入向量
4. 保存到 `runtime/voice/fingerprint.json`（**只存嵌入，不存原音**）

**验证流程**：
1. 收句完成后提取说话人嵌入
2. 与已存储模板计算余弦相似度
3. 分数 ≥ 0.50 → 通过；< 0.50 → 拒绝
4. 拒绝时返回相似度和阈值，但不创建用户账号

**重要声明**：
- 基线样本：同声 0.854、异声 0.190（阈值 0.50）
- **未经真实用户样本评估误拒率/误受率，不能宣称生产级说话人过滤**
- 声纹可通过 UI 或 `/voice/fingerprint` 临时关闭，关闭不删除模板
- 本机声纹只做说话人和背景音过滤，不承担登录认证

### 4.5 语音转文字 (`stt.py`)

```python
# 默认配置
stt_provider: "auto"       # auto = 有远程端点则用远程，否则本地
stt_model: "base"          # faster-whisper 模型大小
stt_language: "zh"         # 中文
stt_compute_type: "int8"   # 量化精度
stt_device: "cpu"          # 推理设备
stt_hotwords: "你好 星子 西子 VoidCube 语音系统"  # 热词上下文
```

**两种模式**：
- **本地模式**（`VOIDCUBE_STT_BASE_URL` 为空）：使用 `faster-whisper base/int8`，支持热词增强
- **远程模式**（设置了 `VOIDCUBE_STT_BASE_URL`）：使用 OpenAI-compatible audio transcription endpoint

**热词**可通过 `VOIDCUBE_STT_HOTWORDS` 环境变量自定义。

### 4.6 文字转语音 (`tts.py`)

```python
# 默认配置
tts_provider: "edge"                   # Microsoft Edge TTS (免费)
tts_voice: "zh-CN-XiaoxiaoNeural"      # 中文女声
```

**支持的引擎**：
| Provider | 说明 |
|----------|------|
| `edge` | Microsoft Edge TTS（免费，默认） |
| `openai` | OpenAI TTS API |
| `elevenlabs` | ElevenLabs 高品质语音 |
| `mistral` | Mistral AI TTS |
| `neutts` | NeuTTS |

### 4.7 会话管理 (`session.py`)

`VoiceSessionManager` 协调所有模式：
- 麦克风开关状态控制
- 单轮 vs 持续监听模式切换
- 声纹录入流程
- 主动提醒播放（服从免打扰/冷却/语音开关）
- 进入 Auto 模式时中断会话并禁用语音控制
- 瞬时流错误退避重试，不自动关闭持续监听

## 六、Supervisor 语音 API

所有 API 通过 Gateway `/supervisor/voice/*` 路由：

| 端点 | 方法 | 用途 |
|------|------|------|
| `/voice/status` | GET | 语音状态查询 |
| `/voice/microphone` | POST | 麦克风开关 |
| `/voice/fingerprint` | POST | 声纹过滤开关 |
| `/voice/owner-template` | POST | 录入手所有者声纹 |
| `/voice/session/start` | POST | 开始单轮语音会话 |
| `/voice/session/interrupt` | POST | 中断当前语音 |
| `/voice/continuous/start` | POST | 开始持续监听 |
| `/voice/continuous/stop` | POST | 停止持续监听 |

## 七、UI 实时音量显示

`/ui/voice-levels` SSE 端点以 100ms 周期独立推送语音实时字段（麦克风音量、状态阶段），避免被常规 `/ui/events` 的 3 秒周期拖慢。

界面依次展示：
```
待唤醒 → 已唤醒/正在聆听 → 等待说完 → 用户输入完成
→ 验证声纹 → 转写中 → 待回复 → 正在回复 → 恢复待唤醒
```

## 八、模型资产管理 (`model_assets.py`)

语音模型存储在 `runtime/voice/models/`（忽略版本控制），下载时按固定 SHA-256 校验：

| 模型 | 文件 | 用途 |
|------|------|------|
| Silero VAD | `silero_vad.onnx` | 语音活动检测 |
| Zipformer KWS | `sherpa-onnx-zipformer-*` | 唤醒词检测 |
| CAM++ | `3dspeaker_speech_campplus_sv_zh_en_16k-common_advanced.onnx` | 说话人嵌入 |

## 九、安全与隐私

1. **背景音不上传**：未唤醒时音频不离开本地 KWS/VAD 循环
2. **声纹只存嵌入**：不存原始音频，不建立用户账号
3. **录音默认删除**：`retain_raw_audio=False`，`finally` 块清理临时文件
4. **TTS 回声保护**：播放期间暂停输入流
5. **模式隔离**：进入 Auto 模式时中断语音、禁用控制
6. **麦克风关闭**：关闭时拒绝所有录音操作，UI 按钮变为不可用
