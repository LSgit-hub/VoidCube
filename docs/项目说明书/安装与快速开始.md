# VoidCube 安装与快速开始

> 更新日期：2026-07-28

---

## 一、环境要求

| 需求 | 说明 |
|------|------|
| Python | **3.14.x**（必须，`>=3.14,<3.15`） |
| 操作系统 | Windows / macOS / Linux |
| Git | 用于替身（Body）Git worktree 管理 |
| 磁盘空间 | ~2GB（含语音模型下载） |

---

## 二、安装

### 2.1 开发安装（推荐）

```bash
# 克隆仓库
git clone https://gitee.com/LSgit-hub/voidcub-CLI.git
cd voidcub-CLI

# 完整安装（含所有可选依赖）
python -m pip install -e ".[all,dev]"

# 或基础安装
python -m pip install -e .
```

### 2.2 可选依赖组

| 组名 | 内容 | 用途 |
|------|------|------|
| `voice` | edge-tts, faster-whisper, numpy, sounddevice, soundfile, sherpa-onnx | 语音交互 |
| `web` | firecrawl-py, parallel-web | 网页抓取工具 |
| `local` | beautifulsoup4, lxml | 本地 LLM 支持 |
| `image` | pillow | 图像生成 |
| `dev` | build, pytest, pytest-asyncio | 开发测试 |
| `all` / `full` | 以上全部 | 完整安装 |

### 2.3 语音模型

首次使用语音功能时，系统会自动下载以下模型到 `runtime/voice/models/`，并按 SHA-256 校验：

| 模型 | 用途 | 大小 |
|------|------|------|
| Silero VAD | 语音活动检测（判断是否在说话） | ~1.5MB |
| sherpa-onnx Zipformer KWS | 唤醒词检测（"你好，星子"） | ~30MB |
| 3D-Speaker CAM++ | 说话人声纹识别 | ~30MB |
| faster-whisper base/int8 | 本地语音转文字 | ~150MB |

## 三、首次配置

### 3.1 选择 AI 模型

```bash
# 交互式选择 API-A（Agent 执行）的 Provider 和模型
voidcube api

# 分别配置 API-A 和 API-B（星子后台推理）
voidcube api --slot a   # Agent 执行模型
voidcube api --slot b   # 星子后台推理模型
```

### 3.2 设置 API 密钥

编辑 `~/.VoidCube/.env`（或运行 `voidcube api` 自动引导）：

```env
# 按需选择 Provider
DEEPSEEK_API_KEY=sk-your-key-here
OPENROUTER_API_KEY=sk-or-your-key-here
DASHSCOPE_API_KEY=sk-your-key-here

# Gateway 内部通信密钥（非开发环境必须设置随机值）
GATEWAY_AUTH_TOKEN=replace-with-a-long-random-value
```

### 3.3 查看完整配置

```bash
voidcube config          # 显示当前配置
voidcube config edit     # 在编辑器中打开 config.yaml
```

## 四、快速开始

### 4.1 交互式对话

```bash
# 启动交互式会话（自动启动后台服务）
voidcube

# 或使用短命令
vc
```

首次启动会自动依次启动：Gateway (6000) → Memory (6001) → Supervisor (6002)。

### 4.2 单次查询（不启动后台服务）

```bash
voidcube chat -q "帮我写一个 Python 脚本"
```

### 4.3 星子模式切换

```bash
# 在对话中执行：
/auto       # 切换到自主进化模式（星子进行记忆整理和自我学习）
/auto-q     # 退出自主进化，回到日常伴侣模式
```

### 4.4 语音交互

```bash
# 启用语音（在 config.yaml 中设置或环境变量）
# VOIDCUBE_VOICE_ENABLED=true

# 打开 Web UI 使用语音控制
# 浏览器访问 http://localhost:6002/ui

# 录入本机所有者声纹（在 UI 中操作）
# 持续监听：点击"开始持续监听"
# 单轮对话：点击"开始语音会话"
```

### 4.5 查看状态

```bash
voidcube status          # 服务状态概览
voidcube status --full   # 完整状态信息
voidcube status --watch  # 实时仪表盘
```

## 七、常见问题

### Q: 启动时报错 "Cannot connect to Gateway"？

A: 检查后台服务是否已启动：`voidcube status`。若未启动，手动启动：`voidcube serve start`。

### Q: 语音模型下载失败？

A: 手动下载模型文件放入 `runtime/voice/models/` 目录。参考 [语音系统说明](语音系统说明.md) 中的模型校验和。

### Q: 如何切换 AI 模型？

A: `voidcube api` 选择 API-A 模型；API-B 模型在 `~/.VoidCube/config.yaml` 的 `stellar` 部分配置。

### Q: Gateway 报 "未授权" 错误？

A: 在 `~/.VoidCube/.env` 中设置 `GATEWAY_AUTH_TOKEN=随机字符串`。开发环境可不设（本机模式）。
