# VoidCube 配置说明

> 更新日期：2026-07-28
>
> 本文档覆盖 VoidCube 的完整配置体系——配置文件位置、环境变量、主要配置段及其含义。

---

## 一、配置体系概览

```text
环境变量 (.env)              优先级最高（启动时读取）
    ↓ 覆盖
用户配置文件 (config.yaml)    持久化配置（通过 voidcube config 管理）
    ↓ 覆盖
代码默认值                   编译时默认值
```

配置存储位置默认为 `~/.VoidCube/`（Windows: `%USERPROFILE%\.VoidCube\`），可通过 `VOIDCUBE_HOME` 环境变量覆盖。

| 文件 | 用途 |
|------|------|
| `~/.VoidCube/config.yaml` | 模型、工具集、终端、浏览器、记忆、Supervisor、语音等全部设置 |
| `~/.VoidCube/.env` | API 密钥、数据库路径等敏感信息 |

## 二、环境变量 (.env)

### 2.1 Provider 凭据

```env
# 按需设置你使用的 Provider
DEEPSEEK_API_KEY=sk-your-key
OPENROUTER_API_KEY=sk-or-your-key
DASHSCOPE_API_KEY=sk-your-key
GEMINI_API_KEY=your-key

# 可选：覆盖 Provider 端点
DEEPSEEK_BASE_URL=https://api.deepseek.com/v1
OPENROUTER_BASE_URL=https://openrouter.ai/api/v1
DASHSCOPE_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
```

### 2.2 Gateway 安全

```env
# 内部服务通信根令牌（非开发环境必须设置随机值）
GATEWAY_AUTH_TOKEN=replace-with-a-long-random-value
```

> ⚠️ 此令牌是**进程认证**，不是人类用户登录凭证。生产环境不配置随机 Token 会导致注册接口处于本机开发模式。

### 2.3 终端后端

```env
TERMINAL_ENV=local        # local | docker | podman | ssh | modal | singularity | daytona
TERMINAL_CWD=.
TERMINAL_TIMEOUT=120
```

### 2.4 语音配置

```env
# 语音开关
VOIDCUBE_VOICE_ENABLED=false

# 声纹过滤
VOIDCUBE_VOICE_FINGERPRINT_PATH=runtime/voice/fingerprint.json
VOIDCUBE_VOICE_FINGERPRINT_THRESHOLD=0.50

# 唤醒词
VOIDCUBE_VOICE_WAKE_WORD=你好，星子
VOIDCUBE_VOICE_WAKE_WORD_REQUIRED=true
VOIDCUBE_VOICE_WAKE_CUE_ENABLED=true

# VAD / 收句
VOIDCUBE_VOICE_SPEECH_START_TIMEOUT_SECONDS=8
VOIDCUBE_VOICE_SPEECH_END_SILENCE_SECONDS=3
VOIDCUBE_VOICE_MAX_UTTERANCE_SECONDS=45
VOIDCUBE_VOICE_VAD_THRESHOLD=0.5
VOIDCUBE_VOICE_WAKE_THRESHOLD=0.25
VOIDCUBE_VOICE_WAKE_SCORE=1.5

# STT（语音转文字）
VOIDCUBE_STT_BASE_URL=          # 留空=本地 faster-whisper，设置=远程端点
VOIDCUBE_STT_API_KEY=
VOIDCUBE_STT_MODEL=whisper-1
VOIDCUBE_STT_HOTWORDS=你好 星子 西子 VoidCube 语音系统

# TTS（文字转语音）
VOIDCUBE_TTS_PROVIDER=edge      # edge | openai | elevenlabs | mistral | neutts
VOIDCUBE_TTS_VOICE=zh-CN-XiaoxiaoNeural
```

### 2.5 调试

```env
DEBUG=false
WEB_TOOLS_DEBUG=false
MOA_TOOLS_DEBUG=false
```

## 三、config.yaml 主要配置段

用户配置通过 `voidcube config` 管理，存储为 `~/.VoidCube/config.yaml`。

### 3.1 API / Provider

```yaml
api:
  provider: deepseek           # API-A 模型 Provider
  model: deepseek-chat
  base_url: ""                 # 留空使用 Provider 默认端点
  api_key_env: DEEPSEEK_API_KEY

stellar:                       # API-B 星子后台推理
  provider: deepseek
  model: deepseek-chat
  base_url: ""
  api_key_env: DEEPSEEK_API_KEY
```

### 3.2 工具集

```yaml
toolsets:
  - terminal                   # 终端/Shell 工具
  - file_operations            # 文件操作
  - web                        # 网页抓取
  - browser                    # 浏览器自动化
  - delegate_task              # 子代理委派
  - skills                     # 技能加载
  - memory                     # 记忆查询
  - mcp                        # MCP 协议工具
```

### 3.3 终端配置

```yaml
terminal:
  backend: local               # 执行后端
  timeout: 120                 # 命令超时（秒）
  cwd: .                       # 工作目录
```

可选后端：`local`, `docker`, `podman`, `ssh`, `modal`, `singularity`, `daytona`

### 3.4 Agent 限制

```yaml
agent:
  max_turns: 90                # 单次会话最大回合数
  gateway_timeout: 1800        # Gateway 超时（秒）
```

### 3.5 记忆配置

```yaml
memory:
  # 记忆召回预算（字符数）
  recall_budget: 8000
  
  # 域配置
  domains:
    agent_interaction: true    # 用户与 Agent 对话
    companion: true            # 星子伴侣记忆
    evolution: true            # 自主进化记忆
```

### 3.6 Supervisor / 星子

```yaml
supervisor:
  service_runtime:
    # 主动提醒策略
    companion_proactive_reminder_enabled: true
    companion_proactive_reminder_tts_enabled: true
    companion_proactive_reminder_cooldown_seconds: 900   # 15 分钟冷却
    companion_proactive_dnd_start: "22:00"               # 免打扰开始
    companion_proactive_dnd_end: "08:00"                 # 免打扰结束
```

### 3.7 辅助模型路由

```yaml
auxiliary_models:
  vision:           # 图片理解
    provider: ""
    model: ""
  web_extract:      # 网页内容提取
    provider: ""
    model: ""
  compression:      # 上下文压缩
    provider: ""
    model: ""
  skills_hub:       # 技能匹配
    provider: ""
    model: ""
  approval:         # 工具审批
    provider: ""
    model: ""
```

### 3.8 代理委派

```yaml
delegation:
  max_subagents: 5              # 最大并发子代理数
  max_iterations: 30            # 子代理最大迭代次数
  blocked_toolsets: []          # 禁止子代理使用的工具
```

## 四、命令行配置管理

```bash
# 查看完整配置
voidcube config

# 在编辑器中打开
voidcube config edit

# 设置单个值
voidcube config set api.model deepseek-chat

# 重跑配置向导
voidcube config wizard

# 配置 API Provider
voidcube api                   # 交互式选择
voidcube api --slot a          # 仅配置 API-A
voidcube api --slot b          # 仅配置 API-B

# 模型信息
voidcube model                 # 显示当前模型
voidcube model --list          # 列出可用模型
```

## 五、配置优先级规则

1. **环境变量** 优先级最高（如 `DEEPSEEK_API_KEY`）
2. **用户 config.yaml** 覆盖代码默认值
3. **`voidcube config set`** 直接写入 config.yaml
4. **`voidcube api`** 交互式修改 Provider/模型
5. **Supervisor 提醒策略** 通过 UI 或 POST `/companion/reminder-policy` 修改，写入 canonical Supervisor 配置段

---

## 六、配置版本兼容性

`config.yaml` 中的 `_config_version` 字段追踪配置格式版本（当前版本：20）。升级 VoidCube 时，CLI 会自动迁移旧格式。

---

## 七、安全注意事项

1. **`.env` 文件不要提交到 Git**（已在 `.gitignore` 中排除）
2. **`GATEWAY_AUTH_TOKEN`** 生产环境必须设置为随机长字符串
3. **API 密钥** 只存在于 `.env` 中，`config.yaml` 通过 `api_key_env` 字段引用环境变量名
4. **声纹模板** 只存嵌入向量，不存原始音频
5. **语音会话原始音频** 默认在 `finally` 块中删除
