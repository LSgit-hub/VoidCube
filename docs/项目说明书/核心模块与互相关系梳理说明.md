## 二、核心模块逐一说明

### 2.1 入口层

| 模块 | 文件 | 职责 | 依赖 |
|------|------|------|------|
| 统一启动器 | `voidcube.py` | console_script 目标；daemon 快捷命令；自动启动 Gateway→Memory→Supervisor | `VoidCube_cli.main`, `VoidCube_cli.ops.serve` |
| CLI 命令路由 | `VoidCube_cli/main.py` | argparse 子命令分发；profile/env 初始化 | `VoidCube_cli.*`, `cli` |
| 交互式会话 | `cli.py` (~10K行) | CLI 交互循环；回调处理；流式渲染协调 | `run_agent`, `VoidCube_cli.chat_*` |

### 2.2 Agent 核心层

| 模块 | 目录/文件 | 职责 | 依赖 |
|------|----------|------|------|
| AIAgent 主循环 | `run_agent.py` | 对话循环；工具回合调度；上下文管理 | `agent/*`, `tools/*` |
| API 请求构造 | `agent/api_request.py` | OpenAI-compatible Chat Completions 请求 | `VoidCube_cli.config` |
| 流式响应处理 | `agent/chat_transport.py`, `agent/stream_response.py` | SSE 解析；文本/推理/工具调用/usage | `agent/api_request.py` |
| 工具执行协调 | `agent/tool_execution.py` | Schema 校验；审批；并发调度；结果顺序 | `tools/*` |
| 上下文压缩 | `agent/context_engine.py`, `agent/context_compressor.py` | 上下文压力管理；自动压缩和恢复 | `agent/prompt_builder.py` |
| 回合终结 | `agent/turn_finalization.py` | 消息写回；诊断；Session/Memory 持久化 | `agent/memory_provider.py` |
| 记忆接入 | `agent/memory_provider.py` | Agent 侧记忆 Provider → Gateway → Memory Service | Gateway `/api/mem/*` |
| 提示词构建 | `agent/prompt_builder.py` | 系统提示词、工具描述、上下文装配 | `tools/*`, `agent/memory_provider.py` |

### 2.4 服务层 (systems/)

#### Gateway（神经中枢）— 端口 6000

| 文件 | 职责 |
|------|------|
| `systems/gateway/internal_gateway.py` | 服务注册/发现；统一 `/api/*` 代理；session 租约；活动/scene/trace 聚合；双泳道 |
| `systems/gateway/agent_adapter.py` | Agent ↔ Gateway 适配 |

**关键数据流**：
```
AIAgent → Gateway /v1/chat/completions → API-A
AIAgent → Gateway /api/mem/* → Memory Service
Supervisor → Gateway /supervisor/* → 内部
外部 → Gateway → Memory / Supervisor / Executor
```

#### Memory Service — 端口 6001

| 文件 | 职责 |
|------|------|
| `systems/memory/memory_service.py` | HTTP API；CRUD；召回入口；维护任务 |
| `systems/memory/domain.py` | 三域隔离；actor 权限矩阵 |
| `systems/memory/recall.py` | 混合召回 Tier1 + Tier2 + Profile + Archive |
| `systems/memory/promotion.py` | 跨域提升候选和正式引用管理 |
| `systems/memory/tier1_to_tier2_bridge.py` | 原始对话 → 压缩记忆的质量门禁 |
| `systems/memory/lexical_index.py` | SQLite FTS5 全文检索 |
| `systems/memory/semantic_index.py` | 向量嵌入索引（可选） |
| `systems/memory/profile_capture.py` / `profile_store.py` | 显式用户事实捕获和管理 |
| `systems/memory/backup.py` | SQLite 备份与轮转 |
| `Mem/src/memai/` | Event/Scene/Arc/Epoch 结构化记忆；Chronicle Scholar LM |

## 三、关键数据流

### 3.1 用户对话（最常见）

```text
用户文本 → voidcube.py → cli.py → run_agent.AIAgent
  → agent/api_request.py (OpenAI Chat Completions)
  → agent/chat_transport.py (SSE 解析)
  → agent/stream_response.py (文本/工具调用/usage)
  ├── 有工具调用 → agent/tool_execution.py → tools/*
  └── 无工具调用 → VoidCube_cli/chat_stream_renderer.py → 终端渲染
  → agent/turn_finalization.py → Memory Tier 1 写回
```

### 3.2 记忆召回

```text
AIAgent prefetch / mem_search
  → agent/memory_provider.py
  → Gateway /api/mem/recall
  → systems/memory/memory_service.py
  → recall.py (Tier1 + Tier2 + Profile + Archive 混合)
  → 相关性/时间/去重/预算排序
  → 临时上下文注入 Agent prompt
```

### 3.3 星子自主任务

```text
Gateway activity + Memory + body + traces
  → Supervisor observation input
  → endogenous_drive.py (need/intent/signal/reflection/proposal)
  → GovernanceEventRepository (先写治理事件)
  → AutonomousChainStore (投影)
  → Gateway supervisor_task 泳道
  → API-A pull → claim → execute → Memory/Supervisor writeback
```

### 3.4 语音交互

```text
持续监听：持久麦克风流 → 本地 KWS"你好，星子" → 本地提示音 ┐
按钮会话：点击"开始语音会话" → 直接聆听                     ├
  → Silero VAD（连续 3 秒静音收句，最长 45 秒）              ┘
  → 可选：CAM++ 声纹验证
  → STT（本地 faster-whisper 或远程端点）
  → Gateway → Supervisor /companion/message
  → API-B 生成回复
  → TTS 合成 → 扬声器播放
  → companion 域 turn pair
  → 持续监听：恢复待唤醒 / 按钮会话：结束
```

### 3.5 替身升级

```text
Supervisor 内生驱动 → 生成改进任务
  → API-A claim 任务
  → prepare_slot_workspace (git worktree add)
  → Agent 在 worktree 中编辑代码 → git commit
  → submit_body_improvement_report
  → mark_candidate → run_probe (5 项检查)
  → Governor 审查 → await_user_consent
  → 用户同意 → activate_slot → Watch Window
  → 通过 → recycle / 失败 → rollback
```

| 跨域提升 | `systems/memory/promotion.py` |
| 自主任务 | `systems/supervisor/autonomous_chain_store.py` |
| 日常伴侣判断 | `systems/supervisor/service_runtime.py` |
| 语音管道 | `systems/voice/` |
| 身体执行 | `systems/execution/facade.py` → `adapters.py` |
| 身体注册/状态 | `systems/body_registry.py` |
| 治理决策 | `systems/governor.py` |
