## 项目概述

VoidCube 是一个**本地运行的 Python 智能体系统**（Python 3.14.x，MIT 协议），包含：

| 组件 | 说明 |
|------|------|
| **CLI Agent (API-A)** | 对话、工具调用、代码执行、子代理委派 |
| **星子 (Supervisor + Memory + API-B)** | 全天候监督者人格；双模式（日常伴侣 / 自主进化） |
| **记忆隔离系统** | 三域（agent_interaction / companion / evolution）强隔离 + 跨域提升引用 |
| **语音交互管道** | KWS 唤醒 → VAD 收句 → 声纹过滤 → STT → 星子理解 → TTS 播报 |
| **替身自进化** | 双槽位 Git worktree + Governor 治理 + Probe 验证 + 用户同意 + Watch Window |
| **Web UI** | 2D 小屋、SSE 实时状态、语音控制面板、提醒策略编辑 |

## 架构速览

```text
用户 → voidcube.py → cli.py → run_agent.AIAgent (API-A)
                              → agent/* (请求/响应/上下文/工具)
                              → tools/* (终端/文件/浏览器/Web/MCP/子代理)

后台服务：
  Gateway (6000) ──→ Memory Service (6001) ──→ MemAI
                 ──→ Supervisor (6002) ──→ Voice/Execution/Body
```
