## 二、写入数据流（Tier1 → Tier2 → Lifecycle）

```mermaid
sequenceDiagram
    participant Agent as AIAgent
    participant GW as Gateway
    participant MS as Memory Service
    participant Bridge as Tier1→Tier2 Bridge
    participant Pipeline as ChroniclePipeline
    participant LLM as MemAI LLM
    participant Lifecycle as 压缩生命周期
    participant DB as SQLite

    Note over Agent,DB: === 实时写入 ===
    Agent->>GW: POST /api/mem/turns/pair
    GW->>MS: add_turn_pair()
    MS->>DB: INSERT turns (speaker, text, scope)
    MS-->>Agent: turn_ids + profile_settlement

    Note over Agent,DB: === 每小时维护循环 (maintenance.py + maintenance_schedule.py) ===
    MS->>MS: _compression_loop() 触发
    MS->>MS: run_tier1_decay_cycle()<br/>relevance *= 0.99^(hours/24)
    MS->>Bridge: run_tier2_bridge_cycle()<br/>每 scope 最多 25 turns

    Bridge->>DB: SELECT expired turns<br/>(7d+ or volume overflow)
    Bridge->>Pipeline: ChroniclePipeline.ingest(turns)

    alt LLM 健康
        Pipeline->>LLM: deepseek-v4-flash 提取
        LLM-->>Pipeline: Event/Scene/Arc/Epoch + Profiles
        Note right of Pipeline: 结果缓存到 llm_cache
    else LLM 不可用
        Pipeline->>Pipeline: 启发式提取 (keyword-based)
        Note right of Pipeline: 标记为 degraded
    end

    Pipeline-->>Bridge: pipeline_result

    Bridge->>Bridge: _evaluate_quality()<br/>per-event: source_support,<br/>identifier_fidelity, polarity
    alt 至少 1 个 event 通过
        Bridge->>DB: INSERT compressed_memories<br/>(event/scene/arc/epoch)
        Bridge->>DB: INSERT turns_archive
        Bridge->>DB: UPDATE turns SET compressed_to_tier2=1
        Bridge->>DB: 写入质量审计
        Bridge->>DB: 更新实体图
    else 全部拒绝
        Bridge->>Bridge: 记录 retry_count + 退避
        Note right of Bridge: 最多 3 次<br/>2^N 小时退避<br/>3 次后永久放弃
    end

    Note over Agent,DB: === 7 天生命周期 cadence (maintenance_schedule.py lease) ===
    MS->>Lifecycle: _apply_compression_lifecycle()
    Lifecycle->>DB: SELECT WHERE compressed_at < cutoff<br/>AND lifecycle_retry_count < 3

    loop 每条到期记忆
        Lifecycle->>LLM: _llm_escalate_summary()
        LLM-->>Lifecycle: 升级摘要
        Lifecycle->>Lifecycle: 质量门禁<br/>source_support ≥ 0.15<br/>identifier_fidelity ≥ 0.8
        alt 通过
            Lifecycle->>DB: INSERT escalated (scene→arc→epoch→final)
            Lifecycle->>DB: UPDATE old SET status='superseded'
        else 拒绝
            Lifecycle->>DB: UPDATE lifecycle_retry_count++<br/>lifecycle_retry_after = 退避时间
            Note right of Lifecycle: 最多 3 次
        end
    end

    Lifecycle->>DB: _purge_expired_memories()<br/>(final 级 90 天审计后)
```

## 五、压缩生命周期状态机

```mermaid
stateDiagram-v2
    [*] --> Event: Tier1→Tier2 桥接<br/>batch=25, 7天 retention
    Event --> Scene: 14 天后升级<br/>source_support≥0.15<br/>identifier_fidelity≥0.8
    Scene --> Arc: 60 天后升级<br/>lifecycle_retry≤3
    Arc --> Epoch: 180 天后升级
    Epoch --> Final: 365 天后升级
    Final --> Purged: 90 天审计后<br/>LLM purge_review

    state Event {
        [*] --> EventActive: weight=1.0
        EventActive --> Superseded: 升级后被取代<br/>weight *= 0.3
    }
    state Scene {
        [*] --> SceneActive: weight=0.7
        SceneActive --> Superseded2: 升级后被取代
    }
    state Arc {
        [*] --> ArcActive: weight=0.4
        ArcActive --> Superseded3: 升级后被取代
    }
    state Epoch {
        [*] --> EpochActive: weight=0.2
        EpochActive --> Superseded4: 升级后被取代
    }
    state Final {
        [*] --> FinalActive: weight=0.05
        FinalActive --> Purged: 删除
    }

    note right of Event
        质量门禁 (per-event):
        - source_support ≥ 0.15
        - identifier_fidelity ≥ 0.8
        - polarity 一致性
        拒绝: retry_count++ (max 3)
        退避: 2^N 小时
    end note

    note right of Scene
        生命周期 cadence: 7 天
        (maintenance_schedule lease)
        每小时轻量检查
    end note
```
