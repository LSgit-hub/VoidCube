# 开发与验证

项目固定使用 Python 3.14.x，依赖以 `pyproject.toml` 为准。常用验证：

```bash
python -m pytest tests/test_documentation_contract.py -q
python -m pytest tests/test_integration_policy.py tests/test_packaging_contract.py -q
python -m pytest -m smoke -q
python -m pytest -q
python -m pytest Mem/tests -q
python scripts/build_wheel.py
```

修改 Gateway/Memory/Supervisor/Execution 时，增加 `tests/test_live_executor_chain.py`；修改记忆时增加 `tests/test_memory_recall.py`、`tests/test_mem_memory_provider.py`；修改工具中断或并发时增加 `tests/test_tool_execution.py`、`tests/test_tool_turn.py`。

涉及模型、鉴权、请求协议、技能或打包时，必须运行退役集成扫描和 wheel 契约测试。文档集合必须保持 `tests/test_documentation_contract.py` 规定的现役文件集合和无断链状态。
