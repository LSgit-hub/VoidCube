# 开发与验证

项目固定使用 Python 3.14.x，依赖以 `pyproject.toml` 为准。常用验证：

```bash
.venv/Scripts/python.exe -m ruff check .
.venv/Scripts/python.exe -m pip_audit --progress-spinner off
.venv/Scripts/python.exe scripts/run_ci_tests.py -- tests Mem/tests -q --cov --cov-report=term
.venv/Scripts/python.exe -m pytest tests/test_documentation_contract.py -q
.venv/Scripts/python.exe -m pytest tests/test_integration_policy.py tests/test_packaging_contract.py -q
.venv/Scripts/python.exe -m pytest -m smoke -q
.venv/Scripts/python.exe -m pytest -q
.venv/Scripts/python.exe -m pytest Mem/tests -q
.venv/Scripts/python.exe scripts/build_wheel.py
```

Windows 开发机应先激活项目 `.venv`，或显式使用
`.venv/Scripts/python.exe`，避免 PATH 中的其他 Python 版本参与验证。Ruff
当前硬门禁覆盖确定性语法与控制流错误；F821 历史问题在 CI 中报告但暂不阻断，
清零后应移除 `--exit-zero`。

修改 Gateway/Memory/Supervisor/Execution 时，增加 `tests/test_live_executor_chain.py`；修改记忆时增加 `tests/test_memory_recall.py`、`tests/test_mem_memory_provider.py`；修改工具中断或并发时增加 `tests/test_tool_execution.py`、`tests/test_tool_turn.py`。

涉及模型、鉴权、请求协议、技能或打包时，必须运行退役集成扫描和 wheel 契约测试。文档集合必须保持 `tests/test_documentation_contract.py` 规定的现役文件集合和无断链状态。
