# 内生驱动核心设计

星子共用一套 Supervisor/API-B 运行时，但使用两个互斥循环。日常伴侣循环读取 VoidCube 内部事件，先判断用户目标和帮助价值，意图不清或没有目标偏差时保持沉默；Auto 循环使用 `systems/supervisor/endogenous_drive.py` 把冻结证据组装为 perception、world model、need、intent、signal、reflection 和 proposal，`planning_runtime.py` 负责计划、议程、不确定性和治理任务投影，`endogenous_drive_prompts.py` 负责 API-B prompt packet 的裁剪和预算。

判断输出必须包含证据、风险、阻塞因素和建议动作。Supervisor 只决定“是否值得做、先观察还是转交、风险如何控制”，不直接拥有工具副作用。转交前追加治理事件，转交后由 API-A 在 `supervisor_task` 泳道 claim 和执行，结果再写回 Memory 与 Supervisor。

自主链路门控初始为关闭；当前 `/auto` 是从 `daily_companion` 切换到 `auto_evolution` 的临时启用开关，`/auto-q` 是收口 Auto 任务并返回日常模式的临时停用开关。两个循环不得并行运行，Auto 模式不消费持续变化的用户活动。
