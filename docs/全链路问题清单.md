## 必须守住的边界

- `/auto` 与 `/auto-q` 当前只负责临时启用和停用自主链路；未来是否移除属于后续设计，不得提前写成现行行为。
- 自主链路启停不得关闭 Gateway、Memory、Supervisor 基础服务，也不得阻断用户主 CLI。
- 用户链路走 `user_chat`；自主任务由 API-A 执行组件走 `supervisor_task`。主 CLI 用户 host 不直接认领自主任务。
- Web 小屋保持只读观察，不增加用户聊天、人工队列管理或身体切换控制入口。
- 替身代码改进属于 API-A 自主执行面；身体切换机械流程属于 Executor；最终激活必须经过用户同意。
- 已退役的模型集成不得以 Provider、OAuth、适配器、别名、回退、技能或打包缓存形式恢复。

## 完成判定

问题只有在主实现、失败路径测试、现役文档和构建/安装契约同时对齐后才可从本清单删除。不得把未验证事项移入“已完成”章节来制造收口状态。
