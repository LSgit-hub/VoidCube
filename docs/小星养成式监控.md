# 卡通职场成长放置养成网页游戏完整方案

## 一、游戏整体定位

名称：《职场小星成长记》

&#x20;类型：Idle 放置养成网页小游戏（HTML5+CSS3+JS+Lottie 动画）

&#x20;美术风格：Q 版软萌卡通，低饱和度马卡龙配色，圆角柔和造型，光影分层细腻，手游级精致 UI，全程 2D 矢量动态角色，无卡顿动画

&#x20;核心机制：四大成长阶段循环挂机养成，自动积累经验值，切换场景触发专属角色动态动画，离线收益，数值升级解锁装饰 / 特效

## 二、技术栈（开箱即用网页方案）

1. 页面结构：HTML5 语义化布局，弹性自适应（手机 / PC 双端适配）
2. 动画核心：Lottie JSON 矢量动画（无锯齿、轻量化，支持循环呼吸、帧动画、翻页、打字同步）
3. 动效辅助：CSS animation 背景微动、灯光渐变、粒子特效
4. 交互逻辑：原生 JS 控制场景切换、动画启停、数值计算、离线挂机
5. 视觉增强：CSS 阴影分层、模糊景深、发光滤镜、渐变柔光、悬浮微动

## 三、四大阶段完整角色 + 场景 + 精细动作拆解（专业游戏级细节）

统一主角设定：Q 版短发职场小人，圆脸蛋、大眼睛、软乎乎肢体，全身分层绘制（头 / 身体 / 手臂 / 道具独立图层，方便独立动效）

&#x20;所有角色基础常驻效果：全局 Idle 呼吸（胸腔缓慢缩放 ±8%）、身体左右轻微摇摆（±3° 缓慢循环，1.8s 周期），不打断阶段专属动作

### 阶段 1：Planning 规划思考模式｜办公室背景

#### 场景：简约治愈办公间

- 底层：浅米色木地板、落地大窗户 + 缓慢飘动薄窗帘
- 中景：浅灰办公桌、绿植多肉、马克杯、便签贴纸、悬浮柔和顶光缓慢明暗呼吸
- 远景：落地窗城市虚化景深、远处写字楼轻微缓慢平移
- 环境微动：窗帘随风缓慢摆动、绿植叶片轻微晃动、桌面水杯热气缓慢上浮粒子

#### 角色精细动作分层（图层分离联动）

1. 基础全局：持续呼吸胸腔起伏、身体左右小幅摇摆
2. 核心动作：双手并拢托住下巴，手肘支撑桌面
3. 头部动画（3s 完整循环）
   - 第 0\~1s：头部缓慢向左倾斜 12°，眼皮半眯思考
   - 第 1\~2s：头部回正，眼珠缓慢左右滑动
   - 第 2\~3s：头部缓慢向右倾斜 12°，轻轻眨眼一次
4. 辅助细节：眉毛微微皱起放松循环，手指轻敲脸颊低频微动
5. 道具联动：桌面便签轻微上下浮动，灯光随头部倾斜亮度微调

### 阶段 2：Learning 学习提升模式｜图书馆背景

#### 场景：暖光治愈卡通图书馆

- 远景：多层弧形木质书架，摆满彩色卡通书籍，书本轻微错落微动
- 中景：柔软米色地毯、落地暖黄阅读台灯（光晕缓慢呼吸明暗）、窗边小盆栽
- 特效：空气中漂浮缓慢上升星光粒子，书页碎屑轻飘

#### 角色精细动作

1. 全局常驻：呼吸起伏 + 身体微摇
2. 肢体：双手捧着厚卡通绘本，手肘自然弯曲举在胸前，身体微微前倾阅读
3. 书本翻页循环动画（4s 周期流畅翻页）
   - 左手扶住书脊固定，右手捏住书页右上角匀速翻页
   - 翻页瞬间书本轻微扭转，页面明暗光影同步切换
   - 翻页完成后书页轻微回弹抖动，书本整体小幅上下浮动
4. 面部：眼睛紧盯书页，眼珠跟随翻页轻微移动，间隔 3s 缓慢眨眼
5. 环境联动：翻页瞬间台灯光晕小幅变亮，书架书本轻微闪烁高光

### 阶段 3：Execution 执行工作模式｜办公电脑场景（同办公室背景，替换前景）

#### 场景：专业工位电脑组合

- 设备：宽大卡通机械键盘、超薄发光显示器、鼠标、立式笔筒
- 特效：显示器屏幕渐变冷暖柔光呼吸，键盘按键独立图层可单独跳动发光

#### 角色精细动作（打字同步按键，高联动质感）

1. 全局：持续呼吸微动不中断
2. 手部高速循环打字动画（1.2s 快速循环，模拟高速工作）
   - 左右手交替起落敲击键盘，手指关节分层动态弯曲
   - **同步联动机制**：手指按下瞬间，对应键盘按键向下凹陷 + 白色高光闪烁，松开回弹
   - 连续打字形成错落按键跳动节奏，不会全部同步僵硬闪烁
3. 显示器反馈：每次敲击屏幕弹出微小白色文字粒子向上飘出
4. 面部：专注睁大双眼，偶尔快速眨眼，嘴角轻微上扬
5. 桌面微动：鼠标伴随手部动作轻微左右滑动，数据线轻微摆动

### 阶段 4：Memory 沉淀复盘模式｜安静书桌场景

#### 场景：原木简约书桌，柔和侧写灯光

- 道具：硬壳笔记本、卡通按压中性笔、桌面小台灯、收纳文件夹
- 光影：侧前方柔光打在笔记本页面，纸面明暗缓慢渐变

#### 角色精细写字动作分层

1. 全局基础呼吸摇摆
2. 肢体：左手轻压笔记本边缘固定本子，右手握笔悬停纸面
3. 写字循环动画（3.5s 一整段书写流程）
   - 笔尖左右小幅往复滑动模拟书写轨迹
   - 笔尖接触纸张时出现黑色细碎墨迹粒子
   - 每写完一段，抬手轻微顿一下，笔尖在空中小幅度转圈思考
4. 道具联动：笔记本随按压轻微形变，笔杆有轻微上下晃动
5. 细节：睫毛缓慢垂落抬起，写完后抬手揉一下眼睛放松

## 四、全局通用 Idle 待机动画（任意切换阶段停止专属动作后触发）

无任务待机状态统一全局动态：

1. 角色胸腔缓慢放大缩小（呼吸动画，2s 周期）
2. 整个身体以腰部为支点左右轻微摇摆（±2.5°，缓慢匀速）
3. 头部缓慢左右小幅转动，间隔 4s 眨眼一次
4. 全身轮廓柔和外发光缓慢明暗呼吸
5. 背景所有装饰保持低频率微动，保持页面不死板

## 五、页面完整布局结构（专业游戏 UI 分层）

页面分 5 大层级，从上到下视觉层级隔离，互不遮挡动画：

### 层级 1：顶部游戏信息 UI（固定悬浮，不遮挡角色）

- 游戏 LOGO《职场小星成长记》发光卡通字体
- 经验值进度条（渐变流光填充动画）
- 挂机收益倒计时、离线收益领取按钮
- 四大阶段切换 Tab 按钮（选中按钮持续发光跳动特效）
- 数值面板：等级、效率加成、每秒经验产出

### 层级 2：场景背景层（底层）

全屏自适应背景图 / 矢量动态背景，带景深模糊，所有环境微动、灯光、粒子全部在此层

### 层级 3：角色 + 道具动画核心层（中间视觉焦点）

角色本体、手持道具、桌椅、电脑、书本、笔全部独立 Lottie 动画图层，支持单独控制启停、速度、透明度

### 层级 4：特效粒子层（覆盖角色上层，半透明）

星光、热气、墨迹、打字文字、书页碎屑浮动粒子，全程持续缓动飘移

### 层级 5：底部功能操作 UI

- 自动挂机开关、加速道具按钮、角色装扮、场景解锁商城
- 一键收取收益、升级按钮（点击有缩放回弹动效）

## 六、交互逻辑与动画切换流程（丝滑无卡顿）

1. 进入页面默认加载 Planning 思考动画，背景同步切换办公室
2. 点击顶部 Tab 切换阶段执行流程：
   - 1）当前角色执行淡出 0.3s 过渡动画
   - 2）场景背景淡入切换对应环境（办公室 / 图书馆）
   - 3）加载对应阶段角色 Lottie 动画，从透明缓慢淡入
   - 4）启动该阶段专属动作循环，保留底层全局呼吸摇摆
3. 挂机自动流转逻辑：

   &#x20;系统定时自动切换四大阶段循环，每次切换附带淡入淡出转场，持续产出经验值
4. 离线逻辑：关闭页面后后台计时，重新打开弹出离线收益弹窗（弹窗带弹跳动画）
5. 按钮交互：所有按钮 hover 放大 + 柔光发光，点击压缩回弹动效

## 七、完整可直接部署网页代码（HTML+CSS + 原生 JS，轻量化，内置动画控制逻辑）

> 说明：代码内置动画控制框架，可直接导入 Lottie 角色动画 JSON 替换资源，自带背景微动、发光滤镜、页面自适应、阶段切换逻辑；注释完整，可直接二次修改美术、动作时长、数值。

## 八、美术动画交付标准（专业游戏品质要求）

1. 角色分层规范：头部、躯干、左右手、独立道具（书本 / 笔 / 键盘）分层导出 Lottie，支持独立动效叠加全局呼吸摇摆，不会动作互相覆盖冲突
2. 帧率统一：所有动画 24fps，循环节点无缝衔接，无卡顿跳帧
3. 光影统一：全程柔和漫反射卡通光影，每个场景专属色调，角色随环境自动匹配色温
4. 动作容错：切换阶段 0.3s 平滑淡入淡出，无生硬闪现，底层全局 Idle 持续运行，角色不会静止僵硬
5. 交互反馈：所有点击、切换、打字、翻页都配套对应视觉特效（发光、粒子、形变）提升游戏手感

## 九、拓展升级功能（可后续添加）

1. 角色皮肤系统：更换卡通形象服装，改变动画配色
2. 场景解锁：积累经验解锁更多办公室、图书馆风格背景
3. 道具系统：咖啡、书本、钢笔加速挂机效率，使用后触发专属特效动画
4. 成就系统：完成累计学习 / 打字时长弹出成就弹窗 + 闪光动画
5. 自动循环挂机：后台定时器自动轮换四大阶段，离线持续产出数值
6. 粒子特效强化：增加雪花、星光、彩带节日动态装饰

## 十、部署使用说明

1. 将代码保存为 index.html，直接浏览器打开即可运行
2. 创建 anim 文件夹，放入 4 组 Lottie 卡通动画 JSON 文件，命名匹配代码内 animRes 路径
3. 如需更换背景，修改对应.bg-xxx 的 linear-gradient 渐变，或替换为图片 background-image
4. 调整动画速度：修改 JS 内 currentAnim.setSpeed () 数值，1 为正常速度，小于 1 变慢，大于 1 加快
5. 调整角色位置大小：修改.char-box 的 width/height、left/top 数值适配屏幕
6. 配色全局统一修改：CSS 内马卡龙渐变、发光色值可一键替换整套美术风格
